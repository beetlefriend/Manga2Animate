# Naming

One name system so the kit, the studio and the token read as one thing.

## The pick: Sakuga

| thing | name | form |
|---|---|---|
| the open-source kit (this repo) | **Sakuga Kit** | `SakugaKit` for handles and the GitHub org/repo |
| the community studio | **Sakuga Studio** | what the site and the social accounts speak as |
| the token | **$SAKUGA** | symbol `SAKUGA`, name `Sakuga` |
| the fee treasury | **Production Fund** | `TOKEN.treasuryWallet` |
| one produced episode | **cut** | anime term for a single shot; `cut-001`, `cut-002` |
| creativity levels | faithful / balanced / **full sakuga** | map to `conservative` / `balanced` / `aggressive` |

Tagline: **Manga in. Anime out. Fees fund the frames.**

Why it works: *sakuga* (作画) is the word anime fans use for the standout,
high-effort animation cuts, which is exactly what the Creative Expansion layer
produces on top of the faithful pipeline. It is recognisable to the audience
that would buy the token, it is pronounceable, and it names the deliverable
rather than the technology.

Availability (checked 2026-10-27 with the Raze and Defined token search tools):
`SAKUGA` exists only as dead micro-tokens on Base / BSC / minor EVM chains, none
on Solana, no liquidity anywhere. Fine to use on Solana; register the handles
early (`SakugaKit`, `sakugastudio`).

## Alternatives, in order

| name | meaning | why it could win | why it did not |
|---|---|---|---|
| **Genga** ($GENGA) | 原画, the key animation drawings | unused as a token; the storyboard-to-video stage is literally key frames | every search for GENGA returns Gengar (Pokemon) tokens; too easy to mis-type |
| **Ekonte** ($EKONTE) | 絵コンテ, storyboard | the storyboard is the method's core artefact; distinctive | obscure outside animation circles; harder to say |
| **Koma** ($KOMA) | コマ, panel | short, "from koma to motion" | taken: Koma Inu on BSC is a live token with real holders |
| **Douga** | 動画, in-betweens / animation | the inserted in-between shots are douga | sounds like "doge"; weak as a brand |
| **Enshutsu** | 演出, episode direction | the creative layer *is* the director role | unpronounceable for most of the audience |

## Voice

- Production-sheet language: cuts, sheets, X-sheet, OK / retake stamps. The site
  already uses it.
- Say "built on Manga2Animate" with the authors' names wherever the method is
  described. It is their research; the kit is the production layer on top.
- Never present a sample number as real. Sample mode wears a stamp.
